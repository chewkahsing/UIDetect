INTRODUCTION

What is UIDetect?

UIDetect is a Chrome browser extension designed to help users understand the security condition of a website before interacting with it.

UIDetect combines multiple security checks and presents the results in a simple dashboard so that users without cybersecurity knowledge can understand potential website risks.

UIDetect is a security assessment tool. A positive result does not guarantee that a website is completely safe.

How UIDetect Works, in Four Parts

This manual is organized around four things UIDetect must clearly declare to every user: how to install it, how it detects a website or interaction to assess, what an assessment result looks like, and which assessment sources (external services and local checks) it relies on.

1. Installation

Run UIDetect_Setup.exe, which installs Python 3.13.14, Ollama and the qwen2.5:3b AI model, starts the local backend, and guides you through loading the unpacked Chrome extension.

See Installation →

2. Detection Methods

UIDetect assesses websites in three ways: a manual Dashboard Scan of the current tab, a Right-Click Scan of a link before opening it, and automatic Security-Sensitive Interaction Detection (login, registration, upload, download, payment).

See Detection Methods →

3. Assessment Result

Every scan returns a numeric Security Score and level, a Final Security Posture (overall status, risk, highest severity, confidence, primary finding), and a plain-language AI Recommendation.

See Assessment Results →

4. Assessment Sources

Results are built from Google Safe Browsing, VirusTotal, OpenPhish, WHOIS/RDAP domain records, and direct HTTPS/SSL/TLS and HTTP security-header checks performed by the UIDetect backend itself.

See Assessment Sources →
STARTUP

Start Using UIDetect

The recommended way to install and start UIDetect is to run:

UIDetect_Setup.exe

The installer installs the UIDetect application and automatically prepares the required software components.

Automatic Setup:

The installer checks for the required Python version, Ollama and the UIDetect AI model. If a required component is missing, the installer downloads and installs it automatically.

  1. Run UIDetect_Setup.exe.
  2. Follow the installation progress shown by the installer.
  3. Wait until the installation is completed successfully.
  4. Launch UIDetect when the installation is complete.

Important:

Do not manually run Install_UIDetect.bat or Start_UIDetect.bat during normal installation. These files are used by the UIDetect installation and startup process.

SETUP

UIDetect Setup

The normal UIDetect installation is performed through UIDetect_Setup.exe.

Step 1 — Run the Installer

Run UIDetect_Setup.exe and follow the installation wizard.

Step 2 — Allow Automatic Component Setup

The installer checks the required Python version, Ollama, the Qwen 2.5 3B AI model and UIDetect Python dependencies. Missing components are downloaded and installed automatically.

Step 3 — Wait for Installation

The installer displays the current installation progress. Do not close the installer while the installation is running.

Step 4 — Start UIDetect

After installation is complete, launch UIDetect. The UIDetect Launcher starts the local backend automatically.

Step 5 — Load the UIDetect Extension into Chrome

In the UIDetect Launcher, click Open Chrome.

On the Chrome Extensions page:

  1. Turn on Developer mode.
  2. Click Load unpacked.
  3. Select the UIDetect extension folder installed on your computer.
  4. Confirm that the UIDetect extension appears on the Extensions page.
  5. Make sure the UIDetect extension is enabled.

The UIDetect extension must be loaded into Chrome before using the website security scanning and interaction detection features.

Manual installation of Python, Ollama and the Qwen 2.5 3B model is not required during normal UIDetect setup.
STEP 1

Python 3.13.14

UIDetect uses Python 3.13.14 to run its local backend and security assessment modules.

Automatic Installation:

The UIDetect installer checks specifically for Python 3.13.14. If the required version is not available, the installer automatically downloads and installs it.
What the Installer Does
  1. Checks whether Python 3.13.14 is available.
  2. Uses the existing Python 3.13.14 installation if it is available.
  3. If Python 3.13.14 is missing, downloads the required installer.
  4. Installs Python 3.13.14.
  5. Verifies that the required Python environment is working.
Existing Python Versions:

A different Python version, such as Python 3.14.x, does not replace the required Python 3.13.14. UIDetect requires Python 3.13.14 for the current project environment.
Advanced Verification:

For troubleshooting, Python information can be checked using:
python --version
STEP 2

Ollama and AI Model

Ollama provides the local AI service used by UIDetect for AI-powered security recommendations. UIDetect uses the qwen2.5:3b model through Ollama.

Automatic Installation:

The UIDetect installer checks whether Ollama is available. If Ollama is missing, the installer automatically downloads and installs it.
What the Installer Does
  1. Checks whether Ollama is installed.
  2. Uses the existing Ollama installation if it is available.
  3. If Ollama is missing, downloads and installs Ollama.
  4. Checks that the Ollama service is available.
  5. Checks whether qwen2.5:3b is installed.
  6. If the model is missing, downloads qwen2.5:3b automatically.
  7. Tests communication with the AI model.
Important:

Downloading the qwen2.5:3b model may take some time. Do not close the installer while the AI model is being downloaded or verified.
Existing Ollama and AI Models:

If Ollama is already installed, the installer uses the available Ollama installation. Other AI models installed in Ollama are not used by UIDetect. UIDetect specifically requires qwen2.5:3b.
Advanced Verification:

For troubleshooting, installed Ollama models can be checked using:
ollama list
The UIDetect AI model should appear as:
qwen2.5:3b
STEP 3

Start the UIDetect Backend

The UIDetect backend is the local server that receives requests from the Chrome extension and performs the website security assessment.

Step 1 — Launch UIDetect

After the installation is complete, launch UIDetect. The UIDetect Launcher starts the local backend automatically.

The UIDetect Launcher displays the status of the backend, Ollama and the AI model.

Keep the UIDetect Launcher running while using the Chrome extension.

Important:

Step 4 — Continue to Chrome

Click Open Chrome in the UIDetect Launcher and continue with the Chrome Extension setup.

USING UIDETECT

How to Scan a Website

  1. Make sure the UIDetect Launcher is running.
  2. Open Google Chrome.
  3. Navigate to the website you want to assess.
  4. Click the UIDetect extension icon.
  5. Click the Scan Website button.
  6. Wait for the assessment to complete.
  7. If necessary, use the Cancel Scan button to stop the running assessment.
  8. Review the Security Score.
  9. Review the Core Protection checks.
  10. Review Website Security and its security headers.
  11. Review Domain Information.
  12. Review VirusTotal analysis.
  13. Review OpenPhish reputation.
  14. Review the Final Security Posture, including risk and confidence.
  15. Read the AI recommendation.
  16. Consider the result before entering sensitive information.
The assessment may take some time because UIDetect performs multiple security checks and may communicate with external security services.
DETECTION METHODS

How UIDetect Detects What to Assess

UIDetect decides what to scan through three independent detection methods. Each one is handled by a different part of the extension before the URL (and, for interactions, the page context) is sent to the local backend for the full security assessment.

Detection Type

UIDetect provides three main detection methods: Dashboard Scan, Right-Click Scan and Security-Sensitive Interaction Detection.

Dashboard Scan: Performs a security assessment of the current website and displays the results in the UIDetect dashboard.

Right-Click Scan: Allows users to assess a website link before opening it.

Security-Sensitive Interaction Detection: Detects actions such as login, registration, upload, download and payment to provide additional security warnings.

Assessment Result Interpretation

The Dashboard Scan presents the assessment results in several sections. Each section provides a different security indicator that should be considered together.

Core Protection: Shows HTTPS, SSL Certificate, TLS and Google Safe Browsing results.

Website Security: Shows the website's security headers and related browser protections.

Domain Information: Provides WHOIS status, domain age and registrar information.

OpenPhish: Provides an additional phishing reputation check.

VirusTotal: Provides an additional reputation assessment using multiple security engines.

Final Security Posture: Summarises the available security findings, risk, severity, confidence and primary finding.

AI Recommendation: Converts the available security findings into a user-friendly recommendation.

Detection Method How It Is Triggered What Is Sent for Assessment
Dashboard Scan User clicks Scan Website in the extension popup. The active tab's URL, page title and meta description.
Right-Click Scan User right-clicks a link and selects the UIDetect scan option from the Chrome context menu. The target URL of the link, before the linked page is opened.
Security-Sensitive Interaction Detection Automatically triggered in the background when the page content indicates a login, registration, upload, download or payment action. The current page URL together with the detected interaction type (for example PAYMENT or LOGIN), so the assessment result and AI recommendation can be tailored to that action.
In every detection method, the actual security checks (Safe Browsing, VirusTotal, OpenPhish, WHOIS, HTTPS/SSL/TLS and security headers) are performed by the local UIDetect backend, not inside the browser. The extension only decides when and what to scan.

UNDERSTANDING RESULTS

Security Score

UIDetect combines multiple security indicators to produce an overall security score.

Security Level Score Meaning
Excellent 90–100 Strong security indicators were detected.
Good 70–89 The website generally shows good security protection.
Moderate 50–69 Some security weaknesses were detected.
Poor 0–49 Significant security weaknesses may exist.
A high security score does not guarantee that a website is completely safe. Users should consider the other security indicators before providing sensitive information.
SECURITY POSTURE

Final Security Posture

UIDetect combines the available security checks to determine a final security posture for the assessed website. This provides a summary of the detected security condition and helps the AI recommendation remain consistent with the assessment results.

Field Meaning
Overall Status The overall security condition determined from the available assessment results.
Risk The overall level of risk identified from the confirmed findings.
Highest Severity The most serious confirmed security finding in the assessment.
Confidence Indicates how complete the assessment is based on the availability of the security checks.
Primary Finding The main confirmed security finding used to guide the user-facing warning and recommendation.
The final security posture is based on the available assessment evidence. An unavailable external security service does not automatically mean that a website is unsafe.
WHERE THE DATA COMES FROM

Assessment Sources

Every UIDetect result is built from a fixed set of assessment sources. Some are third-party reputation services queried over the Internet by the UIDetect backend; others are checks the backend performs directly against the website itself. UIDetect does not send your browsing history, passwords or personal data to these sources — only the website URL being assessed is submitted.

Source Type What It Provides Requires
VirusTotal Third-party reputation API Aggregated verdicts from dozens of antivirus and URL-scanning engines: malicious, suspicious, harmless, undetected and timeout counts, plus an overall reputation score. Internet connection and a configured VirusTotal API key.
Google Safe Browsing Third-party reputation API Checks whether the website is currently known to Google as a source of phishing, malware or unwanted software. Internet connection and a configured Safe Browsing API key.
OpenPhish Third-party public phishing feed Checks whether the URL appears in the community-maintained OpenPhish public phishing feed. Internet connection.
WHOIS / RDAP Domain Records Third-party domain registry data Registrar, registration date, expiration date, domain age and domain status, used to gauge how established a domain is. Internet connection.
HTTPS Check Direct check (UIDetect backend) Confirms whether the website is served over an encrypted HTTPS connection. Internet connection to reach the website.
SSL / TLS Certificate Check Direct check (UIDetect backend) Validates the website's SSL certificate and identifies the negotiated TLS protocol version. Internet connection to reach the website.
HTTP Security Headers Direct check (UIDetect backend) Inspects the website's response headers for HSTS, Content-Security-Policy, X-Frame-Options, X-Content-Type-Options and Referrer-Policy. Internet connection to reach the website.
UIDetect AI (qwen2.5:3b via Ollama) Local AI model, not a reputation source Does not add new evidence. It converts the results already produced by the sources above into a plain-language "About this Website", warning and recommendation. It cannot report a finding that the other sources did not detect. Ollama running locally with the qwen2.5:3b model installed.
Attribution: VirusTotal, Google Safe Browsing and OpenPhish are independent third-party services and are not operated by UIDetect. UIDetect only submits the URL being assessed to these services and displays their responses; it does not modify or endorse their verdicts.
Source Availability:

If a source cannot be reached — for example, because of a missing API key, a rate limit, or no Internet connection — UIDetect marks that source as Unavailable rather than guessing a result. The Confidence field in the Final Security Posture reflects how many sources were actually available for that scan. Always check which sources returned a result before treating a scan as complete.
SECURITY INFORMATION

Core Security Checks

HTTPS

HTTPS is the secure version of HTTP. It helps protect information sent between your browser and the website by encrypting the connection.

Google Safe Browsing

Google Safe Browsing checks whether a website is known to be associated with phishing, malware, or other harmful activities.

SSL Certificate

An SSL certificate helps confirm the identity of a website and enables an encrypted connection between the browser and website.

TLS Version

TLS is the technology that protects information while it travels between your browser and the website. Newer versions generally provide stronger protection.

WEBSITE SECURITY

Security Headers

Security headers are instructions sent by a website's server to tell the browser how certain security features should behave.

Header Simple Explanation
HSTS Helps ensure that the browser uses secure HTTPS connections.
Content Security Policy Helps prevent unauthorized or malicious scripts from running.
X-Frame-Options Helps protect against clickjacking by controlling how the website can appear inside another page.
X-Content-Type-Options Helps prevent the browser from incorrectly interpreting file types.
Referrer Policy Controls how much browsing information is shared with another website.
DOMAIN REPUTATION

Domain Information

WHOIS Status

WHOIS information provides details about the registration history of a domain. UIDetect uses this information to estimate how established a domain appears.

Domain Age

Domain age shows how long a domain has existed. A very new domain may require additional caution, although a new domain is not automatically malicious.

Registrar

The registrar is the company responsible for registering and managing the domain name.

Domain age and registrar information should not be used by themselves to determine whether a website is safe.
INTERACTION ASSESSMENT

Security-Sensitive Interactions

UIDetect can assess security-sensitive interactions performed on a website. These assessments provide additional warnings before users perform actions that may involve accounts, files, information or payments.

Login

Assesses potential risk when entering account credentials.

Registration

Assesses potential risk when creating a new account or providing registration information.

Upload

Assesses potential risk before uploading files or information to a website.

Download

Helps identify potential risk when downloading files or other content.

Payment

Assesses potential risk when performing payment or checkout-related actions.

Risk Levels

Risk Level Meaning
Very Low / Low The interaction shows relatively low risk based on the available assessment.
Medium The user should review the warning carefully before continuing.
High / Critical The interaction may present a significant security concern.
When a High or Critical warning appears:

Carefully consider whether you should continue with the interaction. Do not ignore the warning, especially when the action involves passwords, personal information, file uploads or payments.
PRE-VISIT ASSESSMENT

Right-Click Website Scan

The right-click scan allows users to assess a website link before opening it.

How to Perform a Right-Click Scan
  1. Find a website link.
  2. Right-click the link.
  3. Select the UIDetect scan option.
  4. UIDetect performs the website assessment.
  5. Review the security result.
  6. Decide whether you want to continue to the website.
When to use this feature:

This feature is useful when you receive an unfamiliar link and want to assess its available security indicators before visiting the website.
Important:

A right-click assessment does not guarantee that a website is safe. Review the assessment results carefully before continuing to the website.
PHISHING REPUTATION

OpenPhish Assessment

OpenPhish provides an additional phishing reputation check. UIDetect checks whether the assessed website is listed in the available OpenPhish phishing feed.

Result Meaning
Not Listed The website was not found in the available OpenPhish feed.
Listed The website was found in the available OpenPhish phishing feed and should be treated with caution.
Unavailable The OpenPhish check could not provide a result. Review the other UIDetect security indicators.
A website not being listed by OpenPhish does not guarantee that it is safe. OpenPhish is one of several indicators used by UIDetect.
VIRUSTOTAL ANALYSIS

VirusTotal Assessment

VirusTotal provides an additional reputation check by comparing the assessed website against multiple security engines.

Result Meaning
Safe No significant malicious or suspicious detections were reported by the available security engines.
Warning Some security engines considered the website suspicious.
Unsafe Malicious activity was detected by security engines.
Unknown A reliable classification could not be obtained.

Understanding Detection Counts

Malicious: Number of engines that identified potentially malicious activity.

Suspicious: Number of engines that considered the website suspicious.

Harmless: Number of engines that did not identify malicious activity.

Undetected: Engines that did not detect malicious or suspicious activity.

Timeout: Engines that did not return a result within the available scanning time.

Important:

VirusTotal is an additional security indicator. Users should consider the VirusTotal result together with the other UIDetect security assessments before deciding whether to continue.
USER SAFETY

Recommended Security Practices

UIDetect provides security information to help users make safer decisions when visiting and interacting with websites. Users should also follow basic security practices.

  • Check the website address carefully before continuing.
  • Do not enter passwords into suspicious websites.
  • Be careful when visiting newly registered domains.
  • Do not ignore UIDetect security warnings.
  • Avoid downloading unexpected or suspicious files.
  • Do not upload sensitive documents to untrusted websites.
  • Remember that HTTPS alone does not prove that a website is legitimate.
  • Review multiple UIDetect security indicators instead of relying on only one result.
Important:

UIDetect is a website security assessment tool. Its results provide security indicators and warnings, but they do not guarantee that a website is completely safe.
