INTRODUCTION

What is UIDetect?

UIDetect is a Chrome browser extension designed to help users understand the security condition of a website before interacting with it.

UIDetect combines multiple security checks and presents the results in a simple dashboard so that users without cybersecurity knowledge can understand potential website risks.

UIDetect is a security assessment tool. A positive result does not guarantee that a website is completely safe.
STARTUP

Start Using UIDetect

The recommended way to start UIDetect is to run the installer:

installer\UIDetect_Setup.exe

The installer handles the required UIDetect setup and starts the required components.

The installer runs Install_UIDetect.bat for the required setup process and Start_UIDetect.bat to start UIDetect.
Normal User Workflow:

Run UIDetect_Setup.exe.

Do not manually run Install_UIDetect.bat or Start_UIDetect.bat unless manual troubleshooting or recovery is required.

SETUP

UIDetect Setup

Complete the following setup steps before using UIDetect. The normal installation starts with the UIDetect installer, followed by verification of Python, Ollama, the local backend and the Chrome extension.

For normal use, start with UIDetect_Setup.exe. Manual setup steps are provided for verification and troubleshooting.
STEP 1

Python 3.13.14

UIDetect uses Python 3.13.14 to run its local backend. The backend performs the security assessment and communicates with the Chrome extension.

Step 1 — Check Python Installation

The UIDetect installer handles the required setup process. After installation, open Command Prompt and run:

python --version

Confirm that Python is available and that the installed version is suitable for the current UIDetect project.

Step 2 — Install Python if Required

If Python is not available on the computer, download Python 3.13.14 from the official Python website.

Download Python 3.13.14
Step 3 — Install Python
  1. Run the Python installer.
  2. Enable "Add Python to PATH" if the option is shown.
  3. Continue with the installation.
  4. Complete the installation.
STEP 2

Ollama

Ollama provides the local AI environment used by UIDetect for AI-powered security recommendations. If Ollama is already installed, users do not need to install it again. If it is not available, install Ollama manually before continuing.

Step 1 — Download Ollama

Download Ollama from the official website.

Download Ollama
Step 2 — Install Ollama
  1. Open the downloaded installer.
  2. Follow the installation instructions.
  3. Complete the installation.
Step 3 — Install the UIDetect AI Model

Open Command Prompt or PowerShell and run:

ollama pull qwen2.5:3b
Step 4 — Verify the Model

Run:

ollama list

Confirm that qwen2.5:3b appears in the model list.

Ollama must be available when UIDetect performs AI-powered analysis.
STEP 3

Start the UIDetect Backend

The UIDetect backend is the local server that receives requests from the Chrome extension and performs the website security assessment.

Step 1 — Keep UIDetect Running

A Command Prompt window may appear while the UIDetect backend is running.

Keep the UIDetect backend running while using the Chrome extension.

Important: Do not close the UIDetect backend process while performing website security scans.
Step 2 — Continue to Chrome

Once UIDetect has been started, open Google Chrome and continue with the Chrome Extension setup.

STEP 4

Load UIDetect into Chrome

UIDetect is loaded into Chrome as an unpacked extension during development and testing.

  1. Open Google Chrome.
  2. Enter chrome://extensions/ in the address bar.
  3. Enable Developer mode.
  4. Click Load unpacked.
  5. Select the UIDetect extension folder.
  6. Confirm that UIDetect appears in the Chrome extension list.
  7. Pin UIDetect to the Chrome toolbar for easier access.
If Chrome displays an extension error, check that the selected folder contains the UIDetect manifest.json file.
UIDETECT DASHBOARD

Understanding the Dashboard

The UIDetect dashboard presents the results of the website security assessment in several sections.

Current Website

Shows the website currently being analyzed and its URL.

Security Score

Provides an overall indication of the website's security condition.

Core Protection

Checks HTTPS, SSL Certificate, TLS and Google Safe Browsing.

Website Security

Checks important browser and server security protections.

Domain Information

Provides WHOIS status, domain age and registrar information.

VirusTotal Analysis

Uses VirusTotal results as an additional website reputation indicator.

OpenPhish Assessment

Provides an additional phishing reputation indicator.

AI Recommendation

Converts technical security results into an easier-to-understand recommendation.

Context Assessment

Assesses security-sensitive actions such as login, upload and payment.

UNDERSTANDING RESULTS

Security Score

UIDetect combines multiple security indicators to produce an overall security score.

Security LevelScoreMeaning
Excellent90–100Strong security indicators were detected.
Good70–89The website generally shows good security protection.
Moderate50–69Some security weaknesses were detected.
Poor0–49Significant security weaknesses may exist.
A high security score does not guarantee that a website is completely safe. Users should consider the other security indicators before providing sensitive information.
SECURITY POSTURE

Final Security Posture

UIDetect combines the available security checks to determine a final security posture for the assessed website. This provides a summary of the detected security condition and helps the AI recommendation remain consistent with the assessment results.

FieldMeaning
Overall StatusThe overall security condition determined from the available assessment results.
RiskThe overall level of risk identified from the confirmed findings.
Highest SeverityThe most serious confirmed security finding in the assessment.
ConfidenceIndicates how complete the assessment is based on the availability of the security checks.
Primary FindingThe main confirmed security finding used to guide the user-facing warning and recommendation.
The final security posture is based on the available assessment evidence. An unavailable external security service does not automatically mean that a website is unsafe.
CORE PROTECTION

Core Security Checks

HTTPS

HTTPS is the secure version of HTTP. It helps protect information sent between your browser and the website by encrypting the connection.

Google Safe Browsing

Google Safe Browsing checks whether a website is known to be associated with phishing, malware, or other harmful activities.

SSL Certificate

An SSL certificate helps confirm the identity of a website and enables an encrypted connection between the browser and website.

TLS Version

TLS is the technology that protects information while it travels between your browser and the website. Newer versions generally provide stronger protection.

WEBSITE SECURITY

Security Headers

Security headers are instructions sent by a website's server to tell the browser how certain security features should behave.

HeaderSimple Explanation
HSTSHelps ensure that the browser uses secure HTTPS connections.
Content Security PolicyHelps prevent unauthorized or malicious scripts from running.
X-Frame-OptionsHelps protect against clickjacking by controlling how the website can appear inside another page.
X-Content-Type-OptionsHelps prevent the browser from incorrectly interpreting file types.
Referrer PolicyControls how much browsing information is shared with another website.
DOMAIN REPUTATION

Domain Information

WHOIS Status

WHOIS information provides details about the registration history of a domain. UIDetect uses this information to estimate how established a domain appears.

Domain Age

Domain age shows how long a domain has existed. A very new domain may require additional caution, although a new domain is not automatically malicious.

Registrar

The registrar is the company responsible for registering and managing the domain name.

Domain age and registrar information should not be used by themselves to determine whether a website is safe.
VIRUSTOTAL ANALYSIS

VirusTotal Assessment

VirusTotal provides an additional reputation check by comparing the website against multiple security engines.

ResultMeaning
SafeNo significant malicious or suspicious detections were reported.
WarningSome security engines considered the website suspicious.
UnsafeMalicious activity was detected by security engines.
UnknownA reliable classification could not be obtained.

Understanding Detection Counts

Malicious: Number of engines that identified potentially malicious activity.

Suspicious: Number of engines that considered the website suspicious.

Harmless: Number of engines that did not identify malicious activity.

Undetected: Engines that did not detect malicious or suspicious activity.

Timeout: Engines that did not return a result within the available scanning time.

PHISHING REPUTATION

OpenPhish Assessment

OpenPhish provides an additional phishing reputation check. UIDetect checks whether the assessed website is listed in the available OpenPhish phishing feed.

ResultMeaning
Not ListedThe website was not found in the available OpenPhish feed.
ListedThe website was found in the available OpenPhish phishing feed and should be treated with caution.
UnavailableThe OpenPhish check could not provide a result. Review the other UIDetect security indicators.
A website not being listed by OpenPhish does not guarantee that it is safe. OpenPhish is one of several indicators used by UIDetect.
AI ASSISTANCE

AI Recommendation

UIDetect uses AI to help convert technical security assessment results into a recommendation that ordinary users can understand.

For example, UIDetect may recommend that the user avoid entering sensitive information when several security indicators suggest increased risk.
AI recommendations are intended as security guidance. They should not be treated as an absolute guarantee that a website is safe or unsafe.
CONTEXT AWARE SECURITY

Interaction Assessment

UIDetect can assess security-sensitive interactions performed on a website.

Login

Assesses risk when entering account credentials.

Registration

Assesses risk when creating a new account.

Upload

Assesses risk before uploading files or information.

Download

Helps identify potential risk when downloading content.

Payment

Assesses risk when performing payment or checkout-related actions.

Risk Levels

RiskMeaning
Very Low / LowThe interaction shows relatively low risk based on the assessment.
MediumThe user should review the warning before continuing.
High / CriticalThe interaction may present a significant security concern.
When UIDetect presents a high or critical warning, carefully consider whether you should continue with the interaction.
PRE-VISIT ASSESSMENT

Right-Click Website Scan

The right-click scan allows users to assess a website link before opening it.

  1. Find a website link.
  2. Right-click the link.
  3. Select the UIDetect scan option.
  4. UIDetect performs the website assessment.
  5. Review the security result.
  6. Decide whether you want to continue to the website.
This feature is useful when a user receives an unfamiliar link and wants to assess it before visiting the website.
USING UIDETECT

How to Scan a Website

  1. Open Google Chrome.
  2. Navigate to the website you want to assess.
  3. Click the UIDetect extension icon.
  4. Click the Scan Website button.
  5. Wait for the assessment to complete. If necessary, use the Cancel Scan button to stop the running assessment.
  6. Review the Security Score.
  7. Review the Core Protection checks.
  8. Review Website Security and its security headers.
  9. Review Domain Information.
  10. Review VirusTotal analysis.
  11. Review OpenPhish reputation.
  12. Review the Final Security Posture, including risk and confidence.
  13. Read the AI recommendation.
  14. Consider the result before entering sensitive information.
RESULT INTERPRETATION

Understanding UIDetect Indicators

UIDetect uses simple visual indicators to make technical security information easier to understand.

Safe / Good indicates a generally positive security result.

Warning / Moderate indicates that additional caution may be appropriate.

Unsafe / Poor indicates that potentially serious security concerns were identified.

Unknown means UIDetect could not obtain enough information for a reliable result.

A missing security feature does not automatically mean that a website is malicious. Likewise, a website with a good security score can still contain scams, fake information, or compromised content.
USER SAFETY

Recommended Security Practices

  • Check the website address carefully.
  • Do not enter passwords into suspicious websites.
  • Be careful with newly registered domains.
  • Do not ignore UIDetect security warnings.
  • Avoid downloading unexpected files.
  • Do not upload sensitive documents to untrusted websites.
  • Remember that HTTPS alone does not prove that a website is legitimate.
  • Review multiple UIDetect indicators instead of relying on only one result.
TROUBLESHOOTING

Common Problems

UIDetect cannot scan this page

Some Chrome internal pages and unsupported page types cannot be scanned.

Examples: chrome:// edge:// file://

Scan Failed

First, confirm that UIDetect was started using:

installer\UIDetect_Setup.exe

Also check that your computer has an active internet connection.

AI Recommendation is unavailable

Check that Ollama is installed, the required qwen2.5 3B model is available, and the UIDetect backend is running.

ollama list

Confirm that:

qwen2.5:3b

Scan is taking too long

Wait for the security checks and AI assessment to finish. If you do not want to continue the current scan, use the Cancel Scan button when it is available. You can start a new scan after cancellation.

UIDetect does not appear in Chrome

Open:

chrome://extensions/

Enable Developer mode and confirm that the UIDetect extension has been loaded.

VirusTotal information is unavailable

External security services may occasionally be unavailable or may not return a result. Review the other UIDetect security indicators while the service is unavailable.

Backend is not running

Run the UIDetect installer again:

installer\UIDetect_Setup.exe

The installer performs the required setup process and starts the UIDetect backend.

Do not manually run the batch files during normal installation unless manual troubleshooting or recovery is required.
